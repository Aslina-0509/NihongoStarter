# Nihongo Starter - Japanese Beginner Website

## Files
- index.html (also contains JS scripts in it)
- styles.css

## How to run
1. Extract the ZIP.
2. Open `index.html` in Chrome, Edge, or Firefox.
3. No backend or installation is required.

## Technologies
- HTML
- CSS
- Simple JavaScript

## Sections
Home, Hiragana, Katakana, Vocabulary, Everyday Phrases, Numbers, Basic Grammar, and Practice Quiz.
